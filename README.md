# Intro
This repo contains the instances of green-red-green ZX diagrams that fault-tolerantly prepares certain CSS states found by ChatGPT-5.6-sol xhigh.

The problem is encoded as a linear algebra problem in [here](./PROBLEM.md). GPT is given a [sandbox](https://github.com/LEXUGE/guardian) and asked to solve the problem. The finding it produced is available in [FINDINGS.md](./FINDINGS.md).

GPT is then asked to sweep the [Error Correction Zoo](https://errorcorrectionzoo.org/) and solve as many instances as possible. The result is available in [zoo_codes.json](./data/zoo_codes.json)

Each result in `zoo_codes.json` can be imported and extracted using `Solution.extract` which route the spider using OCM only. The rest of the extraction is easy, involving only unfusing the spiders.

All the codes in this repo is written by human and not generated by LLM.

# Verifying the solution
Run `uv run pytest` which verify each instance fault-tolerantly prepare the code, and also the number of CNOT of each extracted circuit.
